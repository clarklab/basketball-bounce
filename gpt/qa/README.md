# Local visual checks

Run `npm run dev` from `gpt`, then open `/qa/seams.html` to inspect the actual ball material from front, back, left, right, top, and bottom. This page is a development tool and is excluded from Vite's production output.

The seam network follows the conventional construction described by Wilson: two perpendicular great circles plus one continuous winding curve, forming eight panels. The curve is a symmetric spherical-saddle approximation; it does not claim to reproduce a manufacturer's proprietary mold dimensions.

References used for the full-sphere check:

- [Wilson's description of conventional basketball channels, US7909715B2](https://patents.google.com/patent/US7909715B2/en), description of grooves 34a, 34b, and 34c.
- [Wilson official game ball product photographs](https://jp.wilson.com/products/basketball-nba-official-game-ball-7), including the angled side views.

`seams.jpg` captures the corrected six-sided material check. `scene.jpg` captures the scene with the corrected ball.
